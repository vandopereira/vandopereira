# Vando Pereira

Founder and software engineer building local-first AI developer tools and software for real-world operations.

## What I am building

- **[Kaplira](https://github.com/vandopereira/kaplira-overview)** — a local-first desktop architecture workspace that helps developers understand AI-assisted codebases, give agents scoped context, and review changes.
- **[SolifyMed](https://github.com/vandopereira/solifymed-overview)** — clinical and laboratory operations software for scheduling, reception, lab workflows, staff access, finance, and administration.
- **[Papia](https://github.com/vandopereira/papia-overview)** — Cape Verdean Creole translation and cultural discovery products across web and mobile.

The product source repositories are private. The linked public repositories contain product overviews only.

## Selected public work

- **[PixelShift](https://github.com/vandopereira/PixelShift)** — native macOS image conversion and batch-processing app.
- **[PDF to Image](https://github.com/vandopereira/pdftoimage)** — cross-platform PDF-to-image desktop app built with Tauri and TypeScript.
- **[PDF Compressor for macOS](https://github.com/vandopereira/pdf-compressor-macos)** — native SwiftUI batch PDF compressor.
